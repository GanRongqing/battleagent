# 使用说明

## 一、后端环境配置

### 1. 环境要求

* **Python**：3.8.20
* **编译器**：gcc 9.3.0
* **IDE**：PyCharm

### 2. 安装依赖

```bash
pip install numpy>=1.21.0 pandas>=1.3.0 scipy>=1.7.0 shapely==1.8.5 pyproj>=3.0.0 \
networkx>=2.6.0 matplotlib>=3.5.0 cython>=0.29.0 numba>=0.54.0 grpcio>=1.46.0 \
protobuf==3.20.0 nats-py>=2.0.0 redis>=4.0.0 requests>=2.25.0 dill>=0.3.0 \
json5>=0.9.0 allpairspy>=2.5.0
```

### 3. 编译与运行

用 **PyCharm** 打开 `tzb_sim` 目录，配置上述 Python 环境后执行：

```bash
python setup.py build_ext --inplace
```

编译完成后，运行后端服务：

```bash
python base_server.py
```

## 二、前端部署（Docker）

```bash
docker network create my-network

# 导入并启动 DM8 数据库
docker import dm8-tzb.tar dm8:tzb
docker run -d -p 5236:5236 --restart=always --name dm8_tzb \
  --network my-network --privileged=true dm8:tzb \
  bash /opt/dmdbms/bin/DmService start



# 导入并启动前端系统
docker import system-web-tzb.tar system-web:tzb
docker run -d --privileged --cap-add SYS_ADMIN -e container=docker \
  --name system_web_tzb -p 8848:8848 -p 8888:8888 -p 9998:9999 \
  --network my-network --restart=always -e LANG=zh_CN.utf8 \
  system-web:tzb bash /root/start.sh
```

## 五、算法接口

开发者可参考 `grpc_test_demo` 示例，修改其中的 IP 地址为后端主机 IP 后运行。

所有接口调用均通过 **JSON 消息** 发送：

```python
import grpc
import json
from pprint import pprint

from simulation import simserver_pb2
from simulation import simserver_pb2_grpc

_HOST = '192.168.0.100'#修改为启动base_server服务的电脑的ip地址
_PORT = '6000'
channel = grpc.insecure_channel("{0}:{1}".format(_HOST, _PORT))
client = simserver_pb2_grpc.GreeterStub(channel=channel)
user_name = "admin"

# 加载指令
msg = json.dumps({
        "source":"test",
        "ip":"test",
        "user_name": user_name,
        "engine_name": "",
        "flag":"simulation",
        "func_name":"get_state",
        "kwargs":{}
    })
request = client.control(simserver_pb2.MsgStr(msg=msg))
print(request.msg)
data = json.loads(request.data)
pprint(data)
```

> **说明**：
>
> * `func_name` 为要调用的函数名称，例如 `get_state`、`cmd_lock`、`cmd_uav_takeoff` 等。
> * `kwargs` 以字典形式传入函数参数，根据不同接口的需求填写对应键值对。
> * 返回值通过 `request` 获取。

## 六、接口函数说明

### 1. 获取仿真信息

- **函数名**：`get_state()`
- **输入**：无
- **输出**：`state` 字典，结构如下：

```python
state = {
    "time": float,  # 仿真时间
    "white_usv_states": [  # 白方无人艇状态列表
        {
            "name": str,            # 无人艇名称
            "is_alive": bool,       # 存活状态
            "position": list,       # 位置 [x, y]
            "velocity": list,       # 速度向量 [vx, vy]
            "course": float,        # 航向角（0~360°）
            "speed": float,         # 速度大小
            "is_locked": bool,      # 是否被敌方锁定
            "is_locking": bool,     # 是否正锁定敌方
            "is_frozen": bool,      # 是否被冻结
            "locked_attacker": str, # 锁定本艇的敌方单位
            "locking_unit": str,    # 本艇锁定的敌方单位
            "uav": list[str]        # 停靠在艇上的无人机名称列表
        }
    ],
    "white_uav_states": [  # 白方无人机状态列表
        {
            "name": str,          # 无人机名称
            "is_alive": bool,     # 存活状态
            "position": list,     # 位置 [x, y]
            "velocity": list,     # 速度向量 [vx, vy]
            "course": float,      # 航向角
            "speed": float,       # 速度大小
            "battery": float,     # 剩余飞行时间（秒）
            "is_charging": bool,  # 是否正在充电
            "is_at_usv": bool,    # 是否停靠在无人艇上
            "home_name": str      # 当前停靠的无人艇名称
        }
    ],
    "white_observation": [  # 白方视野信息
        {
            "name": str,         # 目标名称
            "position": list,    # 位置 [x, y]
            "velocity": list     # 速度向量 [vx, vy]
        }
    ]
}
```

---

### 2. 运动控制

- **函数名：** `send_command(cmd)`
- **输入：**

```python
cmd = {
    "unit_name": str,
    "target_speed": float,
    "target_course": float
}
```

* `unit_name`：无人机名称
* `target_speed`：起飞速度（m/s）
* `target_course`：起飞航向（°），正北为0，顺时针方向为正
- **输出：** `str`（执行结果）

---

### 3. 锁定指令

- **函数名：** `cmd_lock(p1, p2)`
- **功能：** 指令使 `p1` 锁定 `p2`
- **输入：**

* `p1`：无人艇名称
* `p2`：锁定目标名称
- **输出：** `bool`（锁定结果）

---

### 4. 无人机起飞

- **函数名：** `cmd_uav_takeoff(unit_name, home_name, target_speed, target_course)`
- **输入：**

* `unit_name`：无人机名称
* `home_name`：起飞无人艇名称
* `target_speed`：起飞速度（m/s）
* `target_course`：起飞航向（°），正北为0，顺时针方向为正
- **输出：** `bool`（起飞结果）

---

### 5. 无人机降落

- **函数名：** `cmd_uav_land(uav_name, usv_name)`
- **输入：**

* `uav_name`：无人机名称
* `usv_name`：目标无人艇名称
- **输出：** `bool`（降落结果）
