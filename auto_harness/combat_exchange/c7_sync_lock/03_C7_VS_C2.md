# C7 vs C2
- C2 (LOCK_FIRST_APPROACH) = individual units close **harder/faster** before lock (blanket aggressive
  closing); result: lock rate up in some cases, TTFL slower, outcome mixed.
- C7 = **multi-unit synchronized lock acquisition**: a bounded 2-unit package synchronizes predicted
  time-to-lock so members reach own-lock geometry **near-simultaneously**. No blanket speed-up; no
  unconditional deeper closing; the lever is **coordination/timing**, not closeness. LEAD is *slowed/
  shaped* if it runs ahead, not pushed deeper; package is bounded (2, max 3) and dissolves on timeout.
