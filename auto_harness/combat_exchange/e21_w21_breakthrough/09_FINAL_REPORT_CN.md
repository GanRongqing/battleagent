# 09 — E21 中文最终报告（W2-1 零击毁突破）

## 必答问题
1. **W2-1 零击毁的最关键控制策略瓶颈？** **GLOBAL_REACQUIRE 失联后固定屏列回撤**：无舰船航迹>90s 后
   mission 切到 GLOBAL_REACQUIRE，无目标 USV 收敛到 `SCREEN_X=120km` 并停留 4h+，舰队不再东进接敌。
   C19 移除该回撤后，W2-1 **首次产生真实击毁**，故该机制被**因果确认**。**VERIFIED**。
2. **固定屏列是否造成可验证负面影响？** **是**：C19（仅改该行为）使 W2-1 主动定位 2→108 步、own-lock
   0→69、最近距离 123.4→17.4km、击毁 0→4。**VERIFIED**。
3. **本轮实现了哪些候选？** C19 PRESS_ON_CONTACT_LOSS；C20 STOP_PRESS_AFTER_LOSS；C21 PASSIVE_BEARING_HOMING。
4. **每轮为何有效/无效？** C19：东进接敌→首次击毁，但**全局过度前压**（所有场景损失 20，pooled CER
   0.725→0.492）；C20：首次损失后回撤，W2-4 恢复 12/7，但 W2-1 回到 0（击毁发生在混战中，回撤即失去
   机会）；C21：被动方位归航，安全（W2-4 12/7）但方位太短/太弱，W2-1 仍 0。
5. **是否有真实主动定位增量？** C19 有（2→108 步）；C20/C21 无。
6. **是否出现新的合法交战机会？** C19 有（own-lock 69、min 17.4km、4 次真实击毁，无突破事件）；C20/C21 无。
7. **是否首次实现 W2-1 黑舰真实战斗击毁？** **是（C19，4 艘，非突破/非越界）。** **VERIFIED**。
8. **W2-1 Pure CER 从多少到多少？** **0 → 0.2（C19）**；但因全局回退不可晋级。
9. **最佳候选是否值得回归？** C19 已做全回归：**净回退**（pooled 0.492 < 0.725），不值得晋级。
10. **是否晋级统一主版本？** **否**。C19 仅作诊断里程碑；C20/C21 无 W2-1 收益。
11. **若仍失败，下一轮应攻克什么约束？** **“接敌但不自杀”的持续交战几何**：需要真正的 **hold/standoff
    at contact line 状态 + 预备队/局部优势门控**（仅用合法观测），在保持 W2-1 前出接敌的同时避免全局
    过度前压。这是本轮唯一被证据指向、且尚未实现的方向。

## 失败分析（诚实）
- W2-1 是 20v30 的“箭头突防”伏击，C19 的“全体东进”能把击毁从 0 提到 4，但会让所有场景全灭（过度前压）。
- C20/C21 证明“安全化”会同时抹掉 W2-1 的收益——说明**收益来自前压，而非某个可局部开关的观测量**。
- 因此不能以场景 ID 选择性前压（禁止），必须设计通用的“接敌后保持”机制。
